# Quick Swim

Client-side only. Only your own game needs this mod.

Swim speed rises with the Swim skill. Hold Ctrl in the water and look down to dive, look up to rise. Release Ctrl to hold that depth. Space returns to the surface. The dive stops at the sea floor.

Stamina is spent while you are under. With no stamina, you take damage. Standing still in the water gives stamina back as the Swim skill rises.

Speed, stamina, fog and brightness can be changed in Configuration Manager with F1.
