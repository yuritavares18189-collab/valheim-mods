# Punch Combo

Client-side only. Only your own game needs this mod.

With empty hands, clicks chain into a combo: light, straight, cross, rocket, kick and spin kick. Keep clicking and the combo climbs. A pause returns to the jab. The character does not walk on its own and the body does not spin in place.

With a weapon in hand, nothing changes. In a fight the punch uses the real hit damage.

The window, the damage and the stamina cost can be changed in Configuration Manager with F1.
