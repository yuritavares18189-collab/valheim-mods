# Rota do Baú

Com um baú aberto, o botão **Mover Tudo** joga o inventário nesse baú. O que não couber vai para os baús iguais que estiverem por perto.

**Alt + clique esquerdo** fixa o item. A borda fica verde. Guardar, Mover Tudo e o Ctrl + clique esquerdo não tiram esse item do inventário.

**Ctrl + clique direito** manda só o item clicado para o baú que está aberto. O Ctrl + clique esquerdo continua levando o item para o baú que já tem uma pilha dele.

O botão verde **Guardar** manda as pilhas para o baú certo. O botão dourado **Grupo** junta o que está no baú aberto. O botão vermelho **Voltar** traz de volta o que saiu.

Arma, ferramenta e armadura equipadas ficam no corpo. Pelo Guardar, arma, ferramenta e armadura soltas também ficam. Pelo Mover Tudo, o que está só na bolsa sai, menos o que estiver fixo.
