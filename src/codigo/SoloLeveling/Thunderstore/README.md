# Solo Leveling

Client-side only. Only your own game needs this mod.

Every action gives double experience, and that experience goes into every skill at the same time. Swords, axes, bows, block, run, swim, sneak, jump, fishing, cooking, farming and the rest rise together.

There is no level cap. Past 100 the skill keeps growing, and its effect keeps growing with it.

Open Configuration Manager with F1. The experience multiplier goes from 1 to 5. The default is 2.
