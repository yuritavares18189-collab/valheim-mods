# Monstros do Rio

So no seu jogo.

A vara fica no topo da producao. O clique esquerdo joga. Na fisgada, a barra sobe com embalo enquanto o esquerdo fica segurado e cai quando solta. Ela quica no topo e no fundo. A faixa verde e maior para acompanhar o peixe. Com o peixe dentro da faixa, a barra fica mais leve.

O peixe escolhe um alvo e nada ate ele. Tem cinco jeitos: misto, disparo, liso, fundo e superficie. Da para olhar para os lados. Nao gasta isca.
