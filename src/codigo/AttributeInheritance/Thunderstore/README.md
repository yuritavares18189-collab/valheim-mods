# Attribute Inheritance

Shield with shield: the first one is used up and the second stays. The one that stays keeps the parry, the parry adrenaline and the higher defense. The shield card shows the parry bonus and the parry adrenaline. Armor passes an effect from one piece to another.

While the window is open the character does not walk, look or attack. The mouse is free to click a piece. In F1, Width and Height change the window size.

Upgrading a fused weapon, armor, cape or shield at the forge creates a new piece. This version copies the whole fusion onto the upgraded piece.
